# Lunar Loop

**Lunar Loop** is a systems-driven lunar automation game currently in pre-alpha production. This public repository presents verified in-engine footage from a working Godot 4 build.

## Portfolio footage

[Watch or download the full-quality 4K60 video](https://github.com/Apetrillo99/Lunar-Loop-Portfolio/releases/download/pre-alpha-portfolio/Lunar-Loop-Portfolio-4K60-Pre-Alpha-Final.mp4)

The footage shows the live simulation running in-engine, including:

- Carrier, air, and excavator drone logistics
- Resource harvesting, transport, and depot handling
- Moving conveyor networks and factory production
- Power and water infrastructure
- Vehicle tracks, dust effects, and lunar presentation
- Building placement from the current development build

Camera movement and editing were arranged for this portfolio capture. The machines, resources, animations, routing, and production systems shown are running in the game build; this is not a pre-rendered cinematic.

## Project status

Pre-alpha development build. The game is in its first production stage, so visuals, balance, interfaces, and systems remain subject to change.
